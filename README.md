## Overview

This repository contains my structured notes while learning AI Engineering.

The focus is on understanding concepts from first principles and applying them while building LLM applications rather than simply using APIs.

Topics include:

- Large Language Models
- Prompt Engineering
- Retrieval-Augmented Generation (RAG)
- Fine-Tuning
- AI Agents
- Model Context Protocol (MCP)
- Vector Databases
- Embeddings
- Tokenization
- AI APIs
- Open Source Models
- Production AI Systems
